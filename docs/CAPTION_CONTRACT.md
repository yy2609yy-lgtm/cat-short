# Caption / music contract (AI handoff)

This workbench can render **without any AI station**. A later caption model
should replace only the function below and keep the same I/O.

## Function to replace

`backend/app/services/captions.py` → `build_english_captions(duration: float) -> str`

## Input (already guaranteed by the crop-confirm step)

- Cropped, user-confirmed vertical clip
- Container: MP4
- Video: H.264
- Audio: AAC (may be silent / missing; FFmpeg still lays a music bed)
- Duration: ≤ 60 seconds (product default ≤ 59s)

The current fallback does **not** inspect pixels. An AI replacement may also
read the confirmed render source (`job.asset.local_path` + `job.crop`).

## Output

- **Required:** SRT text, UTF-8
- **Language:** English
- **Count:** 3–6 cues
- **Style:** short lines (a few words each), safe for 9:16 burn-in
- **Optional extra:** the same text can stay as `{job_id}.srt` beside the mp4

FFmpeg burns the SRT (via ASS) into a 1080×1920 / ~30fps H.264+AAC file and
mixes the bundled CC0 bed `backend/assets/music/cozy_afternoon.wav`
(original loop, generated by `scripts/generate_bed.py`, CC0).

Do **not** change the FFmpeg render / technical-check / YouTube private-draft
path when swapping in an AI captioner.
